# cmsegso.github.io
The CMSE GSO Website


Events in the `data/events.json` file are formatted as follows:

```json
[
  {
    "title": "Fall GSO Welcome Social",
    "date": "2026-09-03",
    "time": "5:00 PM",
    "location": "BPS 1515",
    "description": "Meet new students, reconnect with colleagues, and start the semester together.",
    "link": ""
  },
  {
    "title": "September GSO Meeting",
    "date": "2026-09-16",
    "time": "12:00 PM",
    "location": "BPS 1420",
    "description": "A short community update with time for questions, proposals, and announcements.",
    "link": ""
  }
]
```

The public GSO actions index is `actions.html`. Add each future record as a linked entry there and publish its supporting document in `actions/action-[topic]-[year].html`.
